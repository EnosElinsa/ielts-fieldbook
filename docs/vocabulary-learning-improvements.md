# Vocabulary learning improvements

The October 17 review follows dictionary selection through saving, practice and return navigation. The existing system already preserves separate meanings, dated evidence in four skills, FSRS scheduling, source attribution, personal edits and frozen sessions. Improvements should make the next useful learning action clearer without weakening those guarantees.

## Implemented in this batch

New exercises now respect the current reviewed dictionary teaching even when a meaning keeps its original ID. A fully reviewed context supersedes older term-level tasks unless it explicitly keeps their exact definition and example. Permit exposed a stale person-permission sentence in the activity-permission meaning; sentence gaps now use the selected example, and definition/synonym tasks cannot silently borrow the old context. Authored distinction tasks also retain precedence over common confusion prompts. Older public snapshots without optional metadata receive the same protection; personal examples remain independent. Existing started sessions keep their frozen prompts and scoring, and unchanged common contexts keep their reviewed irregular forms and substitutions. This is a correction to task selection, not additional dictionary review coverage.
