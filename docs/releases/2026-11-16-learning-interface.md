# Learning scope and interface refinements

Completing an exact vocabulary learning task previously removed its active assessment binding. Returning from results or a mistake retry then expanded the learning page into the entire wordbook group. Learning pages now read the saved task scope independently of whether it can still complete an assessment. Completed tasks retain their word order, sense IDs, position and original assessment metadata; subsequent practice is self-directed. Refreshing a historical task loads its saved row before displaying cards, and unavailable tasks expose a retry instead of displaying unrelated words. Saving a subset position retains viewed progress elsewhere in the group.

Learning cards use a single teaching column unless substantial supporting content needs another column. Meaning references follow the main content in a full-width footer. An older selected meaning exposes the same current group recommendation as Word details through a separate batch, preserving the original task and its learning evidence.

Phones offer a direct Planning tab, collapsible question-bank filters with removable active values, and expandable future planning days. Current tasks and linked tasks remain expanded. Planning explains when a wordbook is needed to allocate new words. Secondary task actions use a quieter button style. The mobile intensive player compacts after scrolling, can expand without remounting audio, and preserves access to settings and errors. Short landscape screens retain a nonsticky player.

Validation includes regression tests for completed tasks, historical restoration, failed restoration and progress preservation; existing vocabulary practice, navigation, planning, exam and audio coverage; and real-account Chrome checks of the ten-word dictation/retry/return/refresh path. Release checks also cover responsive layouts, production build, vocabulary/identity audits and bundle budgets. No database migration or catalogue replacement is required.
