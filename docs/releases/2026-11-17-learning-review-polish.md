# Learning and review polish

Reading results show the original passage beside the saved answers, initially highlighting evidence for the first visible answer. Locate evidence changes the source without leaving the attempt or losing notes. Shared question instructions are available under Question context. Imported explanations omit an explicitly labelled evidence suffix only when it repeats the same source quotation.

Wrong-answer retry is optional practice. It starts a separate attempt with blank answers and fresh evidence, preserving the original score. Unsaved notes must be saved before starting a retry. Review tasks still complete through their existing evidence and error-reason requirements; a higher retry score is not required.

Vocabulary cards show only their assigned meaning and link to Word details. The redundant recommended-meaning action no longer creates a separate one-word batch. Explicit curriculum meanings now resolve even when absent from an older saved word snapshot; unknown meaning IDs remain unavailable rather than falling back to another meaning. Planned tests retain the exact word/sense list and mode, while optional group practice stays in a disclosure without the plan binding.

Old unfinished tasks can preview verified curriculum corrections, such as escalator's physical staircase meaning instead of its earlier metaphorical dictionary default. Update batch meanings saves a deliberate revision of the same batch, preserving word order, count and assessment mode and recording both sense lists. Tests cannot launch with the old meanings while the new ones are previewed. Choosing original task meanings retains the old contract. Personal edits, custom selections and completed/submitted work are protected; unfinished local assessments block an update, and failures/account changes do not rewrite the original task. Historical evidence and sense-specific mastery are never transferred.

Word details groups the word, pronunciation and practice controls, gives the selected definition its own reading area, and folds reference meanings and provenance. Exact duplicate visible group definitions are omitted without merging sense IDs. Empty example notices are omitted instead of borrowing an unrelated example.

Planning history, task-selection preparation, vocabulary diagram placeholders and writing charts use shared loading components. Button focus and sizing use existing theme tokens.

No database migration or catalogue reimport is required. Account boundaries, saved histories, fixed batches and retained resource URLs are unchanged. Browser checks use intercepted synthetic accounts and keep screenshots outside the checkout.
