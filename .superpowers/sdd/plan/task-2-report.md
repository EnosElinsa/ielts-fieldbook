## Implementation and Task 3 interfaces

`src/domain/vocabulary/media.ts` exports `getVocabularyMedia(entry)` (async), `getVocabularyIllustration(resolved)` (small synchronous sense/context manifest), `aggregateMediaCredits(recordings, image?)`, `legacyVocabularyRecordings(entry)`, and their types. Audio metadata lives in 16 public JSON shards, fetched on demand and cached, with no large metadata JSON imported into application code. Successful requests share a cache; failed requests are evicted. Failure returns `loadError: true` plus safe legacy candidates. `Pronunciation` offers **Retry media metadata**; a subsequent Play also retries the metadata request. Compact controls retain target device fallback; use the full control in details to expose alternatives and metadata retry.

`createVocabularyPlayback().play(entry, options)` retains the old play/stop API. Options add `recording?: VocabularyRecording` for an explicit other-recording action, and `deviceOnly?: boolean` for voice trials. Results add `accent`, `voice`, `fallbackReason`, and `recording`. Automatic playback accepts only metadata-verified exact target UK/US recordings. Missing/error/timeout recording falls back to an exact `en-GB` or `en-US` voice; blocked and cancelled playback do not fall back. No wrong-region English voice is silently used. Device voices load asynchronously and preferred `voiceURI` is saved in localStorage under `fieldbook.deviceVoice.uk/us`; blocked/absent storage and removed voices are handled.

One module-level owner coordinates all instances. Replacing playback stops the previous owner; stale media resolution/failure cannot stop a replacement, and an older owner's unmount does not cancel another owner's speech. Call `stop()` on unmount. Same-row click-to-stop is implemented in `Pronunciation`; practice and other list components can use the same service.

Legacy `pronunciation.uk/us/ipa` is unchanged. Safe HTTP(S) legacy URLs absent from release shards, including personal/imported/old backup entries, remain **unverified accent** candidates requiring explicit playback. Credential URLs, non-HTTP(S) protocols and malformed URLs are discarded. Known wrong-wordform audit candidates are not offered in the alternatives control. Legacy labels alone never certify accent. Playback and components perform no learning activity/account writes.

Reusable UI: `Pronunciation.tsx` accepts `{entry, accent?, options?, compact?}`; `DeviceVoicePreferences.tsx` is standalone for settings integration; `VocabularyIllustration.tsx` accepts `{image}`. The illustration reserves dimensions, lazy loads, hides on failure, and shows caption/author/source/license/change credit. `aggregateMediaCredits` deduplicates sources and preserves per-file attribution. No VocabularyPages/Results/Preferences/controller integrations were edited.
